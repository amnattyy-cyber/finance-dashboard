# W&W FINANCE PERFORMANCE BMA

Executive daily dashboard for SG Finance and Samsung Finance across BMA 1–5.

## Live dashboard

<https://amnattyy-cyber.github.io/finance-dashboard/>

## Data behavior

- Reads live data from the connected Google Sheet through Google Visualization.
- Supports historical report dates.
- Uses the Asia/Bangkok reporting day and rolls over at 20:00.
- Refreshes automatically every five minutes while the page is active.
- Falls back to the embedded 28/07/2026 snapshot if the live source is unavailable.

The repository and GitHub Pages site are public.
